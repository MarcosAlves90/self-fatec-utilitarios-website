# FATEC Utilitarios

Aplicacao focada em calculos academicos para estudantes da Fatec Maua.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS + shadcn/ui

## Como rodar

```bash
npm install
npm run dev
```

## Estrutura

```text
src/
|-- components/  # calculadoras e UI reutilizavel
|-- pages/       # rotas da aplicacao
|-- hooks/       # hooks compartilhados
|-- lib/         # utilitarios de biblioteca
`-- utils/       # regras de negocio
```
